# Конвертер фільмів для телевізора

Невеликий Python-скрипт, який перетворює відеофайли у сумісний із більшістю телевізорів MP4 (H.264/AAC).

## Що робить

- обробляє `.mp4`, `.ts`, `.mkv`, `.avi`, `.mov`, `.m4v`, `.mpeg` і `.mpg`;
- якщо відео вже має кодеки H.264 та AAC — виконує перемультиплексування без втрати якості;
- в інших випадках перекодовує відео у H.264, а звук — у AAC;
- пропускає готові файли, якщо вихідний файл новіший за них.

## Встановлення

Потрібні Python 3 та FFmpeg:

```bash
brew install ffmpeg
```

## Використання

За замовчуванням скрипт бере відео з `~/Downloads/сирі фільми`, а результати зберігає у `~/Downloads/Спільні`:

```bash
python3 convert_films_for_tv.py
```

Вказати власні папки:

```bash
python3 convert_films_for_tv.py -i /шлях/до/вхідних -o /шлях/до/результатів
```

Примусово перезаписати готові файли:

```bash
python3 convert_films_for_tv.py --force
```

Скрипт також приймає шлях до одного відеофайлу через `-i`.
